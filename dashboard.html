Google Wallet integration

Live integration = 3 steps. This demo already generates the pass link shape; connect your Issuer to go live.

  1. Create a Google Wallet Issuer account → make a Loyalty class (program name, logo, colors).
  2. Paste Issuer ID + Class ID below. Your backend signs a JWT for each member (never in frontend).
  3. Customer taps "Add to Google Wallet" → pass appears with QR, stamps balance, promo messages.

Docs: Google Wallet Loyalty passes — classes, objects, JWT save link https://pay.google.com/gp/v/save/{JWT}. Wire Loy.googleWalletSaveURL() in js/loyalty.js to your /api/wallet/jwt?member=ID endpoint.
